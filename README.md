# Blueprint: a Pi Pocket theme

A drafting table for [Pi Pocket](https://github.com/TannerMidd/pi-pocket). Dim cyanotype blue, a faint drawing grid under the conversation, square ink lines, double rules like a drawing's title block, and small mono capitals for labels. Orange pencil crop marks frame your messages, and they slide in around the message box while you type. The light half is a whiteprint: warm drafting paper with Prussian-blue ink.

- Dark and light palettes: Colors → **Blueprint** follows the system's setting.
- Your messages sit on the right on wide screens. Other people's sit on the left.
- Tool calls show as one mono log line, and open into a panel with square survey marks.
- CSS only: it uses just the documented tokens and `data-part` names (`themeApi` 1, Pi Pocket 0.14.0 or later).

## Install

Menu → Extensions → **Discover** → **Themes** → Blueprint, or copy the `blueprint/` folder into `~/.pi-pocket/themes/`. Then choose it in Appearance.
